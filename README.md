# [Borealis] Bagnon: Крестик удаления

Аддон для WoW 3.3.5a (WotLK), русский клиент.

> **Нужен Bagnon.** Аддон работает только вместе с Bagnon (проверен на версии 2.13.2b для 3.3.5).
> Без Bagnon игра его не загрузит: в списке аддонов он будет отмечен как «отсутствует зависимость»,
> и не заработает ни крестик, ни кнопка «Мусор», ни автоматическое слово «УДАЛИТЬ».

## Что умеет

**Слово «УДАЛИТЬ» вписывается само.** Для синих и лучших вещей игра просит вписать слово «УДАЛИТЬ» в окне удаления. Аддон вписывает его сам, остаётся нажать «Да». Это работает при любом удалении, в том числе когда вещь выкидывают из сумки мышью.

**Крестик удаления.** При наведении мыши на вещь в сумках Bagnon в углу ячейки появляется маленький красный крестик. Клик по нему удаляет весь стак. Удалённое пишется в чат. На сохранённых копиях (сумки других персонажей, банк вне банка) крестика нет.

**Кнопка «Мусор».** Когда свободных ячеек в сумках мало, внизу инвентаря Bagnon появляется кнопка «Мусор: N». Клик удаляет самую дешёвую вещь из хлама. Хламом считаются только серые вещи, которые покупает торговец и которые не относятся к заданиям. В бою кнопка прячется.

## Настройки

`/delx` или Интерфейс → Модификации → «Крестик удаления»:

- подтверждение удаления зелёных, синих и фиолетовых вещей крестиком: да / нет (по умолчанию: нет, нет, да);
- размер крестика от 8 до 32 (пока открыта страница настроек, крестики видны на всех вещах);
- показывать кнопку «Мусор»: да / нет;
- при скольких свободных ячейках показывать кнопку «Мусор» (0–20, по умолчанию 3).

## Установка

1. Закрой игру.
2. Распакуй архив так, чтобы папка `borealis_Bagnon_DeleteX` оказалась в `Interface\AddOns`.
3. Убедись, что установлен Bagnon.
4. Зайди в игру и проверь, что аддон включён в списке модификаций.
